# poker-planning

Outil de poker planning pour estimer les stories en équipe, sans publicité.

Cartes : `?` · `0` · `1` · `2` · `3` · `5` · `8` · ✂️ (ciseaux)

## Méthode

Le projet suit le développement piloté par les spécifications avec [OpenSpec](https://github.com/Fission-AI/OpenSpec) :

- `openspec/specs/` : le comportement attendu de l'application, à jour ;
- `openspec/changes/` : les changements en cours (proposition, conception, specs, tâches), archivés une fois livrés.

Commandes Claude Code : `/opsx:explore`, `/opsx:propose`, `/opsx:apply`, `/opsx:archive`.
